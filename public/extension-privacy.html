What this extension does

The extension helps editor.app.br open documents that the page cannot fetch alone (local file:// paths and some cross-origin HTTP(S) URLs). Document bytes are read in your browser and passed to the editor page via postMessage.

Data collection

This extension does not collect, sell, or transmit personal data to our servers. It does not include analytics or advertising SDKs. Document contents are not uploaded by the extension; they remain in the browser process for the editor.app.br tab.

Permissions

  • Host access (optional) — requested only when you open a document from a specific website or file:// path. Chrome shows a permission prompt per origin (not at install). Used so the hidden proxy can fetch that URL and return the bytes to editor.app.br.
  • file:// access (optional; enable “Allow access to file URLs”) — required to open documents from disk without uploading them.

Third parties

The extension only talks to the editor.app.br (and related) page that embeds it, and to the URL the user asked to open. We do not share data with third parties through this extension.
